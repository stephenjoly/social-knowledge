    The actual app

    Everything lands in one private Inbox.

    Every save gets the same careful treatment, whatever it’s about: a readable write-up, the words from the video, and a link back to the creator.

    Open any save to get the useful part.

    • Synopsis & bottom line What it’s about and why it’s worth keeping.
    • Key takeaways The points worth remembering, plus any actions or recommendations.
    • Evidence Supporting quotes from the transcript, caption or frames.
    • Transcript & translation The original words, with a translation if you turn it on.
    • Source Creator, caption, selected comments and the original post.

    ? Then Ask a question across everything you’ve saved. Answers cite the saves they came from.

      Get started

      Run it on your own server.

      Social Knowledge is self-hosted today. You run it on a computer or server you control and connect your own AI provider. There’s no hosted sign-up yet.

      Before you start

      • Docker with Compose on a computer or server you control.
      • Git to download the code.
      • An OpenAI API key for transcription. It can also do the analysis, or pick Cerebras for that.
      • An iPhone with Shortcuts for one-tap saving. Optional: you can also paste links in the browser.

      AI usage is billed by your provider to your own account with them.

      1. 1 Download and configure

        git clone https://github.com/stephenjoly/social-knowledge.git
cd social-knowledge
cp .env.example .env
mkdir -p data vault media

        In .env, set API_TOKEN to a long random value, set DATA_DIR=/data, VAULT_DIR=/vault and MEDIA_DIR=/media, and set APP_URL=http://localhost:8787 for this first local start. Change APP_URL to your real HTTPS address when you open access to other devices. Never commit this file.

      2. 2 Start it

        docker compose up --build -d

        It opens at http://localhost:8787 and listens only on this machine by default.

      3. 3 Claim your administrator account

        Create the first administrator straight away. Keep the app off the public internet until you have: the first person to register becomes the admin. Invite others later from Settings.

      4. 4 Connect your AI

        Onboarding asks for your provider keys. Saving videos needs OpenAI for transcription, plus OpenAI or Cerebras for analysis. Ask only needs the analysis provider. Each key is tested, then stored encrypted.

      5. 5 Add the iPhone Shortcut

        Create a capture-only key and install the Shortcut. Shortcut setup ↓

      iPhone Shortcut

      Save from your iPhone in one tap.

      Share a Reel to the Social Knowledge Shortcut. It confirms the link was saved, then checks for about a minute for the finished capture.

      Download iPhone Shortcut Receipt-only version

      Version 6 · signed · contains no key. You add your own in Shortcuts.

      Heads-up: this signed file currently sends links to social-knowledge.stephenjoly.net. Running your own server? Generate a copy that points at your address instead.

      Make one for your server

      On a Mac, from your checkout. Replace your-server.example with your server’s HTTPS address first.

      python3 scripts/build-shortcut.py --endpoint "https://your-server.example/api/v1/jobs" --output /tmp/save.shortcut
shortcuts sign --mode anyone --input /tmp/save.shortcut --output /tmp/save-signed.shortcut

      Full Shortcut instructions ↗

      1. Create a Shortcut key. In your app, open Settings → API keys and choose Create Shortcut key. It can send links and check on them, but can’t search or export your library.
      2. Install. Open the download in Shortcuts and paste your key when asked. Leave out “Bearer”.
      3. Share a Reel. Tap Share and choose Save-to-Social-Knowledge-Completion-v6.

      Connect your AI first. Without it, the link is still kept and marked so you can retry once AI is set up.
