# Settings font

`inter-latin-wght-normal.woff2` is the Latin variable-weight Inter font from
`@fontsource-variable/inter` version 5.3.0 (48,256 bytes).

- Package: https://www.npmjs.com/package/@fontsource-variable/inter/v/5.3.0
- Upstream: https://github.com/rsms/inter
- License: SIL Open Font License 1.1; see `Inter-LICENSE.txt`.

The `Settings Inter` font-face alias limits this bundled font to Settings.
Vite serves the asset locally; no third-party font request is needed.
